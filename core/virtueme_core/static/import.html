내 기록 넣기

이 화면은 core 서버를 켠 컴퓨터에서 열고, 다른 컴퓨터에서는 서버를 켤 때 나온 토큰이 있어야 열립니다. 올린 파일과 실명은 이 컴퓨터의 프로필 폴더에만 남고, 밖(OpenRouter)으로 나가는 것은 가명·가리기를 거친 문장뿐입니다.

프로필 상태를 불러오는 중

1. 기록 파일 올리기

카카오톡

대화방 → 메뉴 → 대화 내용 → 대화 내보내기 → 텍스트. txt·csv 여러 개나 zip 을 올립니다.

문자

안드로이드: "SMS Backup & Restore" 앱의 XML. 아이폰: 아이클라우드 메시지를 켠 맥의 chat.db 복사본.

인스타그램

설정 → 계정 센터 → 내 정보 다운로드 → JSON 형식. 받은 zip 을 그대로 올립니다.

사진

jpg·png·heic 여러 장이나 zip. 촬영 시각과 위치(EXIF)를 읽고, 위치는 밖으로 보내지 않습니다.

1-2. 흔적 기록 올리기 (선택)

글로 쓰지 않았지만 기기와 서비스에 남은 기록입니다. 각 서비스의 "내 데이터 다운로드" 파일을 그대로 올리고, 받은 zip 을 풀 필요는 없습니다. 기록 처리 때 정서 채점과 주제 묶기에서는 빠지고, 키워드 검색의 근거로 쓰입니다.

유튜브·스포티파이처럼 몇 년 치가 쌓인 곳은 기간을 정하면 빨라집니다.

구글 (유튜브·검색·지도)

takeout.google.com 에서 YouTube 기록과 내 활동(검색)을 JSON 형식으로 내보내기. 받은 zip 을 올리면 유튜브 시청·검색·예전 위치 기록을 한 번에 읽습니다.

구글 지도 타임라인

휴대폰 설정 → 위치 → 위치 서비스 → 타임라인 → 타임라인 데이터 내보내기로 만든 Timeline.json. 좌표는 밖으로 보내지 않습니다.

카드 이용내역

카드사 홈페이지·앱 → 이용내역 조회 → 엑셀(xlsx·xls)이나 CSV 저장. 삼성페이 결제도 연결한 카드의 내역에 나옵니다. 카드 번호는 저장하지 않습니다.

건강 (삼성 헬스·애플 건강)

삼성 헬스 → 설정 → 개인 데이터 다운로드 폴더를 zip 으로, 또는 아이폰 건강 앱 → 프로필 → 모든 건강 데이터 내보내기 zip. 하루 한 건(걸음·잠·운동)으로 모읍니다.

스포티파이

계정 → 개인정보 보호 설정 → 데이터 다운로드로 받은 zip (StreamingHistory JSON). 30초 넘게 들은 곡만 씁니다.

넷플릭스

계정 → 개인 정보 다운로드로 받은 zip 이나 그 안의 ViewingActivity.csv. 예고편과 1분 미만 재생은 뺍니다.

3-2. 장소 이름 붙이기

휴대폰 타임라인 내보내기에는 장소 이름이 없어서, 집·직장이 아닌 곳은 "이름 없는 장소"나 근처에서 찍은 사진으로 부릅니다. 이름을 붙이면 발견 문장과 이야기에서 그 이름으로 부릅니다. 이름을 비우고 저장하면 붙인 이름을 지웁니다.

주소는 적지 마세요. 이 이름은 이야기를 쓸 때 밖(OpenRouter)으로 나갈 수 있습니다. 집 주소, 동·호수, 번지 대신 "단골 카페", "망원한강공원"처럼 부르는 이름을 적어 주세요. 집과 직장은 늘 "집"·"직장"으로만 부릅니다.

4-2. 공유한 카드

발견 문장·책 표지·이야기 대목으로 만든 공유 카드입니다. 카드와 공유 페이지(/s/번호)는 이 컴퓨터에 있고, 링크를 받은 사람이 열면 카드 그림과 그 글이 보입니다. 지우면 그 링크는 더 이상 열리지 않습니다. 이미 내려받아 올린 그림이나 내보낸 사본은 따로 지워야 합니다.
