내 기록 넣기

이 화면은 core 서버를 켠 컴퓨터에서 열고, 다른 컴퓨터에서는 서버를 켤 때 나온 토큰이 있어야 열립니다. 올린 파일과 실명은 이 컴퓨터의 프로필 폴더에만 남고, 밖(OpenRouter)으로 나가는 것은 가명·가리기를 거친 문장뿐입니다.

프로필 상태를 불러오는 중

1. 기록 파일 올리기

카카오톡

대화방 → 메뉴 → 대화 내용 → 대화 내보내기 → 텍스트. txt·csv 여러 개나 zip 을 올립니다.

문자

안드로이드: "SMS Backup & Restore" 앱의 XML. 아이폰: 아이클라우드 메시지를 켠 맥의 chat.db 복사본.

인스타그램

설정 → 계정 센터 → 내 정보 다운로드 → JSON 형식. 받은 zip 을 그대로 올립니다.

사진

jpg·png·heic 여러 장이나 zip. 촬영 시각과 위치(EXIF)를 읽고, 위치는 밖으로 보내지 않습니다.

2. 기록 처리하기

문장 벡터·정서·주제 묶음·관계를 계산합니다. 기록 700건 기준 몇 분 걸리고, 이미 계산한 기록은 건너뜁니다.

3. 사람 관계 붙이기

가명에 관계를 붙이면 이야기와 대화에서 "지인D" 대신 "회사 동기"처럼 부릅니다. 실명은 쓰지 마세요.

5. 내 기록 지우기

이 프로필의 기록, 가명표, 계산 결과, 정답 라벨, 올린 파일, 음악·영상, 전송 로그를 모두 지웁니다. 되돌릴 수 없습니다. 웹 앱에 저장해 둔 이야기와 대화 답도 지운 기록의 것이면 더 이상 보여 주지 않습니다.
