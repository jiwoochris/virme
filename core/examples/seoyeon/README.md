# 샘플 데이터: 가상 인물 윤서연의 90일 (2026-06-01 ~ 2026-08-29)

실존 인물이 아닙니다. 주차별 줄거리를 먼저 정하고, 그 안에서 LLM(claude-sonnet-4.5)이 카카오톡 대화·인스타그램
게시물·사진 설명을 쓰게 했습니다. 줄거리를 알고 있으므로 검색·정서·변화점 결과가 맞는지 채점할 수 있습니다.

## 들어 있는 것

| 파일 | 형식 | 분량 |
|---|---|---|
| `kakao/대학친구들.txt` | 카카오톡 PC 내보내기 (구분선 + `[이름] [오후 1:00]`) | 메시지 466건 |
| `kakao/엄마.txt` | 카카오톡 모바일 내보내기 (점 날짜) | 158건 |
| `kakao/정우진.csv` | 카카오톡 Mac 내보내기 (csv) | 297건 |
| `instagram/` | 인스타그램 "내 정보 다운로드" JSON (한글은 실제처럼 latin-1 깨짐 형태) | 게시물 16, 스토리 29, DM 92 |
| `photo_manifest.json` | 휴대폰 사진 44장과 인스타그램 사진 45장의 촬영 시각·장소·검색어 | 89장 |
| `raw_weeks.json` | LLM 이 쓴 주차별 원본 | 13주 |

사진은 저작권 때문에 저장소에 넣지 않았습니다. `uv run python examples/seoyeon/fetch_photos.py` 가 위키미디어
공용에서 받아 `photos/` 와 `instagram/media/` 에 넣고, 촬영 시각·GPS 를 EXIF 로 적고, 출처를 `CREDITS.photos.md` 에 남깁니다.

## 다시 만들기

```bash
uv run python examples/seoyeon/generate.py        # LLM 호출, 약 3분 (결과가 매번 조금씩 다름)
uv run python examples/seoyeon/build_exports.py   # raw_weeks.json → 카카오톡·인스타그램 내보내기 파일
uv run python examples/seoyeon/fetch_photos.py    # 사진 받기
```

`eval/seoyeon_silver.json` 은 이 데이터에 붙인 은 라벨입니다. 데이터를 다시 만들면 기록 ID 가 바뀌므로 라벨도 새로 만들어야 합니다.
