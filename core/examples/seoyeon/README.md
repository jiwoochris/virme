휴대폰 타임라인 내보내기에는 장소 이름이 없어서 집·직장 말고는 "방문: 장소 (1시간 3분 머무름)"로 들어갑니다.
좌표는 로컬 DB 에만 있고 밖으로 나가지 않습니다. 소설 재료 컬럼(`virtueme columns`)은 이름 없는 장소를 근처에서 찍은 사진의
자동 태그로 부르고("바다 사진을 찍은 곳"), 사용자가 `places --name` 으로 이름을 붙이면 그 이름을 씁니다. 시연에서는 아래처럼
자주 간 곳 여섯 군데에 이름을 붙였습니다.

```bash
$P places --name "id:ChIJf9ce69a326fQx=망원한강공원" --name "id:ChIJ9476be00916Qx=동물병원" \
          --name "id:ChIJ02d813fa0f8Qx=성산일출봉" --name "id:ChIJ8f6a522cbb4Qx=협재해수욕장" \
          --name "id:ChIJ62852cb96e5Qx=애월 숙소" --name "id:ChIJ66dfa1620c1Qx=여의도공원"
$P columns
```

- 집과 직장을 빼면 가장 자주 간 곳은 망원한강공원입니다. 20일을 갔고 주로 저녁에 갔습니다.
